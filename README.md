**Technologies Used:**

### ✅ Task 2 - Tic Tac Toe AI
A command-line Tic Tac Toe game where users can play against the computer.

**Technologies Used:**
- Python

---

### ✅ Task 3 - Image Captioning AI
An AI application that generates captions for images using the BLIP (Bootstrapping Language-Image Pre-training) model from Hugging Face.

**Technologies Used:**
- Python
- Transformers
- Pillow
- Matplotlib

---

### ✅ Task 4 - Recommendation System
A simple recommendation system that suggests movies based on the user's favorite genre.

**Technologies Used:**
- Python

---
